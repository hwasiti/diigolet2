Diigolet 2 · a Diigo highlighter that survives strict sites

Highlight any page, save it to Diigo

One small bookmark that sites with strict security policies cannot block. Works in Chrome and Firefox on desktop and in Chrome on Android, where extensions do not exist. Highlights land in your normal Diigo account and render in Diigo's own website, apps and extension.

Install

Desktop: drag this button to your bookmarks bar.

Diigolet 2

Android Chrome: tap Copy bookmarklet below, bookmark any page (star in the menu), then edit that bookmark: name it dl2 and paste the copied text as its address. Chrome Sync does not carry bookmarklets to phones reliably, so make the phone bookmark on the phone.

Using it

  1. Android: on the page you want to read, tap the address bar, type dl2 and tap the suggestion with the bookmark star. Opening it from the bookmarks list does not work; Chrome loses the page. Desktop: click the bookmark.
  2. A pen appears at the bottom right and your existing highlights for the page paint themselves.
  3. Select text; a colour palette appears next to the pen. Tap a colour to save the highlight.
  4. To remove a highlight, use your Diigo library or Diigo's own tools for now; the bookmark is at Android's size limit, so removal moves into the helper window in a later version.

What the pen and the status mean

  • Blue pen straight away: this site allows the hidden helper frame; saves are silent.
  • Grey pen: this site blocks frames. Tap the pen once: on desktop a small helper window opens and stays; on a phone a helper tab opens, talks to Diigo and closes itself within a couple of seconds, dropping you back on the article. Each save then flashes that tab once.
  • "Sign in to Diigo": the browser has no Diigo login. Sign in at diigo.com in this browser and tap the pen again.
  • "Popups isolated" or "Popup blocked": the site blocks frames and severs or blocks popups, so no channel to Diigo could be opened on this page.
  • "Helper unreachable": the helper page did not answer within a few seconds; check the connection and tap the pen again.

Updating

The bookmark is only a thin client; all Diigo logic lives in a helper page on this site and updates itself. Re-install the bookmark only when this page says the bookmark itself changed.

Signing in and privacy

You must be signed in to diigo.com in the same browser. The bookmarklet never sees your password; it uses the login cookie your browser already has. Saves travel through the helper page on this site, which only relays requests for the page you are reading, sends Diigo the text you selected plus the page's text for matching, and stores nothing.
