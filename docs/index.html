Using it on Android Chrome

  1. Open the page you want to read, tap the address bar, type dl2, and tap the suggestion that shows the bookmark star. Opening it from the bookmarks menu does not work; Chrome loses the page.
  2. A pen button appears at the bottom right. Select text with the normal handles; a colour palette appears.
  3. Tap a colour. The highlight paints and saves. Tap an existing highlight and choose Remove to delete it.

If the pen is grey, this site blocks embedded frames. Tap the pen once: a helper tab opens, talks to Diigo and closes itself, dropping you back on the article. Each save then flashes that tab for a second. If a save cannot be confirmed at all, the bookmarklet opens Diigo briefly to deliver it.

Updating

The bookmark contains the whole engine, so it does not update itself. When this page announces a new version, delete the old bookmark and drag or copy the new one again on each device.

Signing in and privacy

You must be signed in to diigo.com in the same browser. The bookmarklet never sees your password; it uses the login cookie your browser already has. Saves travel through a small helper page on this site that only relays requests for the page you are reading, and stores nothing.
